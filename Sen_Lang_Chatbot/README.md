# Multilingual Sentiment-Aware Chatbot

## About
The Multilingual Sentiment-Aware Chatbot is a culturally-conscious AI assistant capable of interacting in multiple languages while maintaining emotional intelligence. It automatically detects the user's language and sentiment to provide responses that are not only linguistically accurate but also culturally appropriate, using regional greetings and etiquette.

## Features
- Real-time Language Detection: Automatically identifies English, Gujarati, Hindi, Spanish, and Spanish.
- Sentiment Analysis: Evaluates the emotional tone of interactions to adjust response style.
- Dynamic Cultural Routing: Tailors greetings and etiquette (e.g., "Namaskar", "Jay Shree Krishna") based on detected language.
- Technical Content Support: Capable of providing code snippets (Python, C++, etc.) while maintaining the conversation in the native script.
- Privacy-First: Runs entirely on local infrastructure using Ollama.

## Tech Stack
- Frontend: Streamlit
- LLM Orchestration: Ollama
- Language Detection: langdetect
- Sentiment Analysis: TextBlob
- Language: Python

## Model Used
- Large Language Model: Gemma 2 (via Ollama)
- Language Detection Model: langdetect
- Sentiment Model: TextBlob

## How it Works
The application processes user input through a two-stage NLP pipeline. First, `langdetect` identifies the primary language, and `TextBlob` analyzes the emotional polarity. This information is used to select a culturally-specific system prompt. For example, if Hindi and positive sentiment are detected, the chatbot is instructed to respond with warmth and use traditional Indian greetings. The final response is generated by the Gemma 2 model, optimized for multilingual and technical tasks.

## How to Run

### 1. Clone the Repository
```bash
git clone <repository-url>
cd Sen_Lang_Chatbot
```

### 2. Install Dependencies
```bash
pip install streamlit ollama textblob langdetect
```
Download the necessary TextBlob corpora:
```bash
python -m textblob.download_corpora
```
Ensure Ollama is running and Gemma 2 is pulled:
```bash
ollama pull gemma2
```

### 3. Run the Application
Start the Streamlit server:
```bash
streamlit run app.py
```
